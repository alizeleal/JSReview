Operadores: Relacionais, Lógicos e Ternários

Operadores Relacionais

== | Igualdade (mesmo valor)

!= | Diferença (valores diferentes)

=== | Igualdade Estrita (mesmo valor e tipo de variável)

!== | Diferença Estrita (valores diferentes ou tipos diferentes)

< | Menor que

> | Maior que

<= | Menor ou igual a

>= | Maior ou igual a

in | Verifica se a propriedade existe no objeto

Observação: o resultado é sempre um booleano: True ou False

Operadores Lógicos

&& | E lógico

|| | Ou lógico

! | Não lógico

Observação: o resultado é sempre um booleano: True ou False

Operador Ternário

condição ? valor_se_verdadeiro : valor_se_falso

Exemplo: let resultado = (a > b) ? "A é maior que B" : "B é maior que A";

Operador de Coalescência Nula

?? | Se o valor da esquerda for nulo ou indefinido, retorna o valor da direita

Exemplo: let resultado = a ?? b;

Operador de Atribuição Lógica

||= | Se o valor da esquerda for falso, atribui o valor da direita

Exemplo: let resultado = a ||= b;

Operador de Atribuição Nula

??= | Se o valor da esquerda for nulo ou indefinido, atribui o valor da direita

Exemplo: let resultado = a ??= b;

Operador de Atribuição de Desestruturação

Desestruturação de Objetos: { a, b } = objeto;

Desestruturação de Arrays: [ a, b ] = array;

Exemplo: let { a, b } = objeto;

Exemplo: let [ a, b ] = array;

Operador de Atribuição de Desestruturação com Padrão

Desestruturação de Objetos: { a = 1, b = 2 } = objeto;

Desestruturação de Arrays: [ a = 1, b = 2 ] = array;

Exemplo: let { a = 1, b = 2 } = objeto;

Exemplo: let [ a = 1, b = 2 ] = array;

Operador de Atribuição de Desestruturação com Padrão e Rest

Desestruturação de Objetos: { a = 1, b = 2, ...resto } = objeto;

Desestruturação de Arrays: [ a = 1, b = 2, ...resto ] = array;

Exemplo: let { a = 1, b = 2, ...resto } = objeto;

Exemplo: let [ a = 1, b = 2, ...resto ] = array;

Operador de Atribuição de Desestruturação com Padrão e Rest e Spread

Desestruturação de Objetos: { a = 1, b = 2, ...resto } = { ...objeto };

Desestruturação de Arrays: [ a = 1, b = 2, ...resto ] = [ ...array ];

Exemplo: let { a = 1, b = 2, ...resto } = { ...objeto };

Exemplo: let [ a = 1, b = 2, ...resto ] = [ ...array ];

Operador de Atribuição de Desestruturação com Padrão e Rest e Spread e Default

Desestruturação de Objetos: { a = 1, b = 2, ...resto } = { ...objeto, a: 3 };

Desestruturação de Arrays: [ a = 1, b = 2, ...resto ] = [ ...array, 3 ];

Exemplo: let { a = 1, b = 2, ...resto } = { ...objeto, a: 3 };

Exemplo: let [ a = 1, b = 2, ...resto ] = [ ...array, 3 ];

Operador de Atribuição de Desestruturação com Padrão e Rest e Spread e Default e Rest

Desestruturação de Objetos: { a = 1, b = 2, ...resto } = { ...objeto, a: 3, ...resto };

Desestruturação de Arrays: [ a = 1, b = 2, ...resto ] = [ ...array, 3, ...resto ];

Exemplo: let { a = 1, b = 2, ...resto } = { ...objeto, a: 3, ...resto };

Exemplo: let [ a = 1, b = 2, ...resto ] = [ ...array, 3, ...resto ];
