Ordem de Precedência das Operações

5 + 2 * 3 = 11

(5 + 2) * 3 = 21

5 + 2 * 3 - 4 / 2 = 10

5 + 2 * (3 - 4) / 2 = 6

5 + 2 * (3 - 4) // 2 = 5

5 + 2 * (3 - 4) ** 2 = 7

5 + 2 * (3 - 4) // 2 ** 2 = 5

5 + 2 * (3 - 4) // 2 ** (1/2) = 5

5 + 2 * (3 - 4) // (2 ** (1/2)) = 5

Operadores de atribuição

+= | a = a + b => a += b

-= | a = a - b => a-+= b

*= | a = a * b => a *= b

/= | a = a / b => a /= b

%= | a = a % b => a %= b

//= | a = a // b => a //= b

**= | a = a ** b => a **= b
